# Supported routers

| Manufacturer | Model | UI language | Status |
|---|---|---|---|
| TP-Link | Archer C80 | English | Automatic driver; enable/restore tested on a real device |
| Other | Models exposing DHCP option 3 and 6 | Any | Manual Setup only |

Support is model- and firmware-specific. Do not assume another TP-Link model is
compatible merely because its interface looks similar.

See [router-compatibility.md](router-compatibility.md) for the manual-mode matrix.
